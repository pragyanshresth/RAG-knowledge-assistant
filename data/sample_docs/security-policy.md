# Security Policy
## 5.1 Reporting a Cybersecurity Incident
Report suspected incidents immediately to security@example.com or the 24/7 hotline at ext. 4911. Do not delete files or power off the device. The security team will respond within one hour.
## 5.2 Software Access Requests
Request software through the IT portal. Requests need manager approval and, for admin rights, a security review. Standard software is provisioned within 3 business days. Unapproved software may not be installed.
